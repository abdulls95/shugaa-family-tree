# Shugaa Family Tree — شجرة آل شجاع

نسخة أولية مجانية تعمل كـ Web App / PWA ومهيأة لـ GitHub Pages + Supabase.

## الإعداد
- Supabase URL: `https://vfewmznnmmppuaaidbnw.supabase.co`
- Publishable key موجود في `config.js`
- لا يوجد Secret key داخل المشروع.

## النشر على GitHub Pages
1. أنشئ مستودعًا باسم `shugaa-family-tree`.
2. ارفع جميع محتويات هذا المجلد إلى جذر المستودع.
3. Settings → Pages → Deploy from a branch.
4. Branch: `main` و Folder: `/ (root)`.
5. افتح رابط Pages وسجّل دخولك بحساب Supabase.

## مهم
المفتاح الموجود في `config.js` هو Publishable key فقط. لا تضف Secret key أو service_role key إلى GitHub أو الواجهة.

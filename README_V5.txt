شجرة آل شجاع — V5
واجهة جديدة مستوحاة من أسلوب تطبيقات شجرة العائلة الحديثة

مهم:
هذه نسخة أصلية خاصة بشجرة آل شجاع، وليست نسخًا حرفيًا لكود أو علامة موقع آخر.

التغييرات:
- شريط إدارة جانبي على الكمبيوتر/الآيباد الكبير.
- شريط سفلي على الجوال.
- صفحة الشجرة أصبحت مركز العمل.
- شريط بحث / مشاركة / ملاءمة / ترتيب.
- زر إضافة سريع للإدارة.
- عرض الشجرة يركز على النسب ويُبقي الزوج/الزوجة داخل ملف الشخص حتى لا تتداخل الخطوط.
- قائمة الأفراد وملف الشخص والإدارة أعيد تصميمها بأسلوب أبسط.
- إعدادات الإدارة أصبحت أقرب إلى شاشة إعدادات مستقلة.
- نظام Supabase والأكواد والطلبات والصلاحيات والدمج لم يتغير.

لا يحتاج SQL جديد.

لا تستبدل config.js.
